# Непрерывная геометрия Завода — 26.10.2026

Первый пространственный анализ полного collider export. Это промежуточный
референс конструктора; производство BN mapgen и назначение этажей не выполнены.

## Сцены

`scene_plan.json` построен чтением настоящих day/night ScenesPreset из
`factory_metadata.zip`, а не выбором по похожим именам. В каждом варианте
14 сцен: 10 общих и 4 собственных. only_offline сохранён отдельным флагом.
Дневной анализ включает общий набор и дневные сцены; ночные не накладываются.
Factory_Day/Factory_Night названы активными сценами вне имеющегося экспорта;
их роль и runtime-создание объектов остаются непроверенными.

## Геометрия

`space_analysis.json` привязан к SHA-256 проверенного исходного экспорта.
Меши преобразованы в общую систему Unity X/Y/Z. Включены активные enabled
non-trigger компоненты слоёв LowPolyCollider, DoorLowPolyCollider и Terrain;
слои разрешены по именам из TagManager, а не взяты из предположения об индексе.
Меши и Box представлены геометрическими треугольниками. Sphere/Capsule не
аппроксимируются этим анализатором; статистика исключений сохранена.

Точный duplicate key учитывает Mesh, матрицу, слой и convex либо параметры Box.
Результат содержит 755054 треугольника экземпляров. Это не количество
уникальных треугольников ресурсов и не доказательство коллизии в PhysX.

`sections.png` и `sections.json`: сечения Y=-1.65, 1.05, 4.05, 8.05.
Кадр вычислен по пяти основным сценам здания/офиса/лаборатории. Геометрия за
кадром не удалена из анализа. Копланарные треугольники и касания в точке не
выдаются за стены; пересечения по рёбрам/вершинам проверены тестами.
Это абсолютные высоты срезов, а не четыре назначенных этажа.

## Высоты и переходы

Для каждой сцены сохранены суммы площадей горизонтальных треугольников по
высоте с шагом 0.05. Включены поверхности обоих направлений; крыша, низ
перекрытия, оборудование и наложения могут давать пики. Поэтому сумма площадей
не равна площади пола и сама по себе не назначает проходимую поверхность.

Крупные компоненты дополнительно записаны с source component ID, Mesh name
и собственными высотными пиками. Например, Admin_office_Floor_01_COLLIDER
содержит поверхности около Y=1 и Y=4.3; Laboratory_F_01_COLLIDER — около
Y=0.05 и Y=3.35. Один компонент может объединять пол, стены и потолок.
Соседние зоны имеют разные отметки; равномерная глобальная нарезка этажей
не сохраняет такую структуру автоматически.

249 записей имеют stair/ladder/ramp в имени объекта либо Mesh. Среди них
есть перила, переносные стремянки и вертикальные лестницы на оборудование.
Это список деталей для проверки, **не 249 игровых лестниц**. Для каждой записи
сохранены мировые границы и source ID; accepted_route=false во всех случаях.

Следующая операция — выделить опорные поверхности с проверкой свободного
объёма над ними и связей по пролётам. После этого назначать локальные высотные
зоны и переходы BN. Численные уровни BN и метрический масштаб ещё не утверждены
анализом; оси изображения не означают географический север.

## Воспроизведение

Нужны NumPy, Matplotlib и UnityPy 1.25.4; версии NumPy/UnityPy сохранены в отчёте.
Входные архивы хранятся отдельно от git. Выходная папка должна быть новой.

```sh
python tarkov/tools/client_data/analyze_factory_space.py factory_collision_export.zip --metadata factory_metadata.zip --output factory_space_study
python tarkov/tests/locations/client_space_test.py -v
```

Программа также пишет world_triangles.npz — воспроизводимый промежуточный
массив, не включённый в git. Шесть геометрических тестов и реальный анализ
прошли; Unity runtime, BN runtime и проходимость этим не проверялись.
