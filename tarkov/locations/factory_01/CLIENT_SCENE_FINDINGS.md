## Границы доказательства

- Пользовательские MonoBehaviour пока не декодированы; первая попытка чтения
  обычным type tree завершилась несовпадением размера. Имена классов/состояния
  дверей и динамические переключения не восстановлены.
- Active/enabled/non-trigger не равно коллизии с игроком: ещё нужны слои,
  матрица столкновений и runtime-поведение. Баллистические коллайдеры могут
  отличаться от коллайдеров движения.
- Нет полного меша полов, проверенного human clearance, связности лестниц,
  соответствия SVG, метрического масштаба BN или перевода в BN-сетку.
- Матрицы и индексы проверены, но движок Unity/игра не запускались.

## Воспроизведение

Установить `UnityPy==1.25.4` в отдельное Python-окружение. Затем:

```sh
python tarkov/tools/client_data/audit_factory_scenes.py factory_geometry_sample.zip --output audit.json
python tarkov/tests/locations/client_transform_test.py -v
```

ZIP читается в памяти без распаковки и выполнения игровых компонентов;
выходной JSON создаётся только по новому пути. Три автономных теста проверяют
цепочку поворота/масштаба/сдвига, активность родителя и отказ на повреждённых
родительских ссылках. Отчёт дополнительно получен на настоящем образце клиента.

### Что можно убрать

Архивы `factory_collision_dependencies.zip` и
`factory_structure_dependencies.zip` больше не нужны для данного маршрута
чтения коллайдеров: новый экспорт содержит ссылочную геометрию. Пользователю
разрешено удалить их с Drive (около 112 MB); автоматического удаления не было.
`factory_geometry_sample.zip`, metadata, globalgamemanagers и inventory пока
сохранить: полный экспорт коллайдеров не заменяет пользовательские компоненты,
исходную иерархию и общие менеджеры для будущего чтения интерактивных объектов.
Сам новый экспорт хранить как исходник следующего этапа.

### Следующий этап и границы

Теперь доступны офис, лаборатория и остальные выбранные сцены без ручного
подбора sharedassets. Сначала нужно разделить общие и дневные/ночные сцены,
собрать пространственные поверхности и оценить высоты/лестницы. Не накладывать
оба варианта в одну карту: например, Day/Night Light содержат по 120 активных
LowPoly MeshCollider и 72 Box. В обоих Culling есть TEMP_GROUND_COLIDER при
Y=-16; его нельзя автоматически принять за игровой подвальный этаж.

Выборка экспортёра — 18 путей внутри Factory_Rework из BuildSettings. Это
не доказательство того, что все прочие внешние/активные сцены и runtime-
созданные объекты учтены. В пресетах дополнительно названы активные
Factory_Day/Factory_Night вне этого каталога; их роль остаётся отдельной
проверкой при необходимости. Состояния дверей и MonoBehaviour ещё неизвестны.
Нет проверки Unity runtime, прохода персонажа, сетки BN или нового mapgen.

Пользователь явно разрешил публикацию отчётов и данных, полученных из клиента,
в GitHub после предыдущего отказа автоматической проверки. Новые сырые игровые
контейнеры и полный Mesh-архив в репозиторий для этого этапа не добавляются.
