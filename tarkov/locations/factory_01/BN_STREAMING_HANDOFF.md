# Ошибка BN при выборе удалённых лестниц в native-тесте

Основа: BN `554950f3635f50ddd1d32c6e1b6e2bdee9842bd6`, без изменения ядра.
Запуск: https://github.com/ProxysRE/CataclysmAI-BN/actions/runs/40224035747
Исходный коммит теста: `9d848ac20a0d1bb7ec046fef6e9108c5ecbd8530`.

Компиляция, modcheck и генерация прошли. В первом seed 20261025 JUnit содержит
0 failures / 0 errors и 2 464 384 успешных assertions, включая 27 подъёмов и
27 спусков. Однако процесс вернул 1: `Treating result as failure due to error
logged during tests`. Итог native-проверки НЕ принят.

В system-err повторяется `mapbuffer.cpp:1261`, `unload_omt: skipping free of
submap ... reality bubble still references it`, измерение
`trkv_factory_probe_constructor`. Первые сообщения относятся к субкартам
(128..129,142..143,z=-10..10), затем к другим участкам. Журнал и защитная ветка
`mapbuffer::unload_omt` указывают на попытку выгрузки ещё используемых субкарт.
Тест переставлял avatar между удалёнными парами через обычный `setpos`, вызывающий
перецентровку bubble. Это свидетельство проблемы стриминга/выгрузки, а не доказанная
ошибка самих лестничных terrain. Точный порядок удаления запросов требует
исследования владельцем ядра; здесь исправление ядра не вносится.

Для узкой проверки лестниц тест теперь входит в то же измерение с заранее
выбранной загрузочной областью вокруг очередной пары, проверяет обычный
`vertical_move(1,false)` и `vertical_move(-1,false)`, затем возвращается в исходное
измерение перед выбором следующей пары. Генерация не заменена моком, позиции
лестниц и asserts сохранены. Ошибки не подавляются и не признаются допустимыми.
На seed отведено 900 секунд вместо 600: исходный процесс уже занимал около 557
секунд вместе с загрузкой данных, а новая проверка добавляет переходы измерений.

Такой запуск проверяет подъём/спуск из неподвижной горизонтальной области.
Он НЕ закрывает стриминг большого Завода. До приёмки игровой карты нужны обычное
движение через границы submap и большие перемещения, проверка отсутствия debug
errors, сохранение/загрузка и повторный вход. Карта с найденными debug errors
не должна объявляться полностью готовой по зелёным assertions.
