# Локации DDA, отсутствующие или неполные в основном контенте BN

Срез исходников проекта: DDA `c19e95bc96d2`, BN `c621aaf42fa1`.

Core JSON registrations, all overmap terrain declarations, full mapgen file inventory and six focused mapgen files. Mods excluded. Not an exhaustive semantic diff of every interior/nested variant.

В списке отсутствует именно указанная локация или версия, а не весь тип зданий.
