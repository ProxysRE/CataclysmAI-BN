# Noncombatant civilians and monster dialogue

DDA c19e95bc96d27d8bef8e2e246a63cd4cd6f89974; BN c621aaf42fa182473aad10feea2b55647704dcf1. SOURCE_MANIFEST.json authenticates the original nine civilian talk topics and stock BN factions. Monster/group originals and selection loaders are also authenticated by eldercare_fauna/SOURCE_MANIFEST.json; existing core loader baselines come from xedra_creature/SOURCE_MANIFEST.json and the project's pinned npctalk.cpp.

Three source human types are adapted: panicked person, petrified person and terrified parent. The existing BN human faction, HUMAN species/material, avoidance, normal corpses and zombie conversion are retained. Their source negative aggression/morale and explicit aggro_character=false keep them neutral to the player; they are living people, not hostile-feral replacements. The root has source 75 hp, speed 90, with the stationary subtype at speed 20. Source names, descriptions, parent lines and response graphs are preserved. Source conversation/modern guilt/path flags become the native chat property, stock BN GUILT and PATH_AVOID_DANGER_2. BN guilt penalties are not the complete DDA NPC-murder consequence system.

The chat graph is an embedded mtype property, not a fake NPC or NPC conversion. BN's existing chat menu offers a nearby-person entry when a neutral living speaker with a graph is visible within two tiles on the same floor. A selection menu opens the source response graph using uilist. Random source lines are retained; ampersand narration markers are removed for display. Escape closes the dialogue; talk uses the existing chat action's time cost. No trade/follower commands, effects or opinion changes are fabricated. Source portraits and monster parrot attacks/snippets are not ported in this slice. Real NPC dialogue, orders, shouts and terminal archives keep their existing paths. The graph is read-only, and no per-monster conversation state needs save serialization; type IDs and ordinary monster state continue through BN saves.

The root's source half_life=4, age_grow=1 and GROUP_CIVILIANS_UPGRADE are retained, using existing BN evolution timing and its user settings. The upgrade group is used only by single-monster evolution. A controlled flattening resolves its sole GROUP_FERAL child: source outer leaf weights are multiplied by the feral total 100, and feral leaf weights by the parent weight 180. The resulting total 90600 preserves exact rational selection probabilities. Both engines' single-monster GetRandomMonsterFromGroup ignore pack sizes, time windows and quantity costs; those are deliberately absent in this specialized table. It is not a general algorithm for flattening map spawn groups. Source timing behavior follows BN's existing evolution implementation, not a new scheduler.

Four armed civilian types and three civilian-containing map groups remain staged. Their conditional firearms, equipment and target selection are not claimed as implemented. Full nursing-home and retirement-community generation remains disabled until the whole dependency and runtime chain is ready.

Validation includes source graph/weight-fraction/reference/collision guards, exact embedded patch checks, installed payload equality and stale-payload rejection. Native tests exercise loaded inherited dialogue, neutral player attitudes, zombie hostility toward people, out-of-range chat refusal, invalid-link rejection and evolution selection. Windows compilation, source/installed native runs, visible in-range menu interaction, save/reload and whole-site generation remain pending.
