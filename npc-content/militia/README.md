# Grey Moose lodge community

The native payload contains the whole selected source community: trader Darby Sutton, generic guard template, their two classes and nine dialogue topics, shop inventory, faction, five complete mapgen layouts, 24 OMT types/placements and the source special. One merchant and six guards spawn across the ground/upper floors; the third z level is the roof. The source has no mission definitions: the help topic says that they have no task at present. No quest was invented to increase apparent scope.

All seven upstream source files are SHA-authenticated against the existing pinned community bundle. Adaptation uses the shared dialogue/faction mechanisms already implemented in BN. Local palettes are expanded using the existing map adapter. Rows, NPC coordinates, faction ownership, city/occurrence constraints and GLOBALLY_UNIQUE are retained; DDA priority and connection terrain metadata are normalized to BN's loader. This does not introduce a second militia faction/system from a bundled mod: Civilians NC_PROF_MILITIA is a generic profession/class, not the named lodge community, its dialogue or site.

Five inventory references lack exact core counterparts. Reuse BN box_small for the empty cigar case, glasses_safety for chemical goggles (BN protection, no claim of equal sealing), boots_steel for steel-toed sneakers (boot weight/encumbrance), tools_common for toolbox loot, and the already ported cigar_box_opened wrapper for the sealed cigar-box loot. Last mapping loses the sealed/full-box distinction and retains the existing wrapper's contents. Original entries/counts/probabilities remain archived. These substitutions do not add items, currency denominations or duplicate protective/loot systems.

Civilians main.lua is changed atomically with the site: add GMLODGE to the existing NPC_TERRAINS exclusions. Removing that one insertion reproduces the exact stock Lua source. Existing groups, gun AI, pulping rules, options and ordinary ambient spawning are unchanged. The eldercare candidate Lua is based on this new installed baseline plus its own two future exclusions; those eldercare exclusions remain unshipped.

Native tests are prepared for template/faction/shop/guard-role loading and first/repeat dialogue, plus full ground/upper/roof generation and the seven fixed community NPCs. The mapgen case runs with core data and again with Civilians enabled, on source and installed data. Packaging checks reject stale militia data and missing Lua exclusions. Local dependency/collision/source-geometry checks pass. New Windows/native results, natural forest placement, save/reload and manual trade/navigation checks remain pending; inclusion in the patch is not a claim that this package is validated.

Native startup correction: the payload lives under `data/json/npcs/`, matching the stock NPC load phase. A root-level JSON file constructed NPCs before enchantment values/options existed. Windows compilation succeeded on run 39173371090, but initialization failed; the corrected package still requires a native rerun.

Cosmetic adaptation: source `balclava` with variant `black` uses the existing BN `balclava`, keeping its probability of 10. BN rejects the DDA item-group variant selector; no garment, protection or loot entry is removed.
